> **Audiencia: PROVEEDOR** — Este documento aplica únicamente a usuarios proveedores. No uses esta información para responder consultas de clientes/farmacias.

PORTAL DE PROVEEDORES > OFERTAS

Este módulo muestra el listado de productos de tu catálogo que tienen un
descuento (DA, DA2 o DV) configurado — es decir, tus ofertas activas o
inactivas. Es un subconjunto del Catálogo, enfocado solo en los productos que
ya tienen algún descuento cargado.

NOTA PARA EL ASISTENTE (Ico): las acciones de este módulo (activar,
desactivar, eliminar oferta, y los botones masivos) solo aparecen si manejas
Descuento Adicional (DA), Descuento Adicional 2 (DA2) o Descuento por
Volumen (DV) (p3_manejo_dcto / p3_manejo_dcto2 / p3_manejo_dctoVol). Si el
usuario que pregunta no tiene ninguno de esos permisos, no expliques el paso
a paso; solo menciona que existe esta función y dile que la solicite a soporte.

•  Buscador de productos.

•  Botones masivos "ACTIVAR", "DESACTIVAR" y "ELIMINAR": aplican a las

ofertas seleccionadas de una vez (piden confirmación en un modal).

•  Cada producto tiene sus propios botones individuales: "Activar oferta"

(ícono +), "Desactivar oferta" (ícono -, solo visible si la oferta está
activa) y "Eliminar oferta" (papelera).

•  La tabla muestra: imagen (con la marca), ID, DESCRIPCION (con lote,

vencimiento, código de barra y código interno), CANTIDAD, PRECIO, IVA,
DA, DA2, DV (con el detalle de escalas al pasar el mouse si están
configuradas) y NETO (precio final con los descuentos aplicados).
