MAYOR VARIEDAD DE PRODUCTOS

este reporte tiene como objetivo mostrar la amplitud del catálogo. Mide la
cantidad de "renglones" (es decir, productos distintos o SKUs únicos) que ofrece
cada proveedor. Es fundamental para entender quiénes son los aliados que
aportan la mayor diversidad de opciones a la plataforma.

•  Distribución y Escala: El eje vertical mide la cantidad de productos
distintos (escalado de 0 a 7.000) y el eje horizontal agrupa a los
proveedores. Fiel al estándar del sistema, las barras se ordenan de
mayor a menor, creando un ranking visual de quién ofrece el portafolio
más amplio.

•  Detalle al Pasar el Cursor: La gráfica mantiene su interactividad. Al

posicionar el cursor sobre la primera barra (azul oscuro), el sistema revela
que el líder de este segmento, DROGUERIA EL LOBO, C.A., aporta un
total exacto de 6.582 renglones distintos al catálogo.

•  Botón Regresar: Debajo del gráfico hay un botón para volver a la

pantalla anterior. Si no hay datos para mostrar, el sistema despliega el
mensaje "No hay información disponible para mostrar el gráfico" en vez
del gráfico.
