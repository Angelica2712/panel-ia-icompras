VECES EN 1ER LUGAR (RNK-1)

Este gráfico es un indicador directo de competitividad económica. "RNK-1"
significa "Ranking 1" o "Primer Lugar". El objetivo de este panel es mostrar en
cuántos productos (o cuántas veces) un proveedor ofrece el mejor precio
absoluto en comparación con el resto. Es una herramienta fundamental para que
los compradores sepan quiénes son sus aliados más fuertes para generar ahorro.

•  Distribución y Escala: El eje vertical mide la cantidad de incidencias o
productos (escalado de 0 a 3.000) en los que el proveedor es el más
barato. El eje horizontal agrupa a los proveedores. Fiel al estándar de la
plataforma, las barras se ordenan de mayor a menor, creando un ranking
visual inmediato de competitividad.

•  Detalle al Pasar el Cursor: El gráfico mantiene la interactividad habitual. Si
el usuario posiciona el cursor sobre una barra el sistema revela el detalle: el
proveedor DROGUERIA LOBO BLANCO C.A. se posiciona en primer lugar
de precio para un total de 2.474 "unidades" o renglones.

•  Botón Regresar: Debajo del gráfico hay un botón para volver a la

pantalla anterior. Si no hay datos para mostrar, el sistema despliega el
mensaje "No hay información disponible para mostrar el gráfico de mejor
precio" en vez del gráfico.
