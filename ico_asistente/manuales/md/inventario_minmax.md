GenPedAuto). Si NO la tiene: no expliques el paso a paso, solo menciona que
existe esta funcionalidad (configurar mínimos y máximos por producto para que
el sistema pida automáticamente) y dile que debe solicitar a soporte que se la
activen. Si SÍ la tiene, explica el módulo con el detalle de abajo.

OPCION DE INVENTARIO > DÍAS MÍNIMOS Y MÁXIMOS

Este módulo solo aparece en el menú de Inventario si tienes activados los
"Pedidos automáticos" (Generación de Pedido Automático). Aquí defines, producto
por producto, las reglas que usa el sistema para decidir cuándo y cuánto pedir
automáticamente.

SEGURIDAD: si tu cuenta tiene activada la verificación en dos pasos (Google
Authenticator), al entrar a este módulo se te pedirá el código de autenticación
antes de poder ver o modificar nada; la sesión queda autenticada por 10 minutos.

PANTALLA PRINCIPAL

•  Barra de acciones: muestra el total de productos, y dos botones:

o  "Exportar a Excel": descarga el listado con los mínimos, máximos y

múltiplos configurados.

o  "Carga masiva excel": permite subir un archivo Excel para configurar

los valores de muchos productos a la vez.

•  Buscador de productos.

•  Cada producto se muestra en una tarjeta con su imagen (clicable, va a

la ficha del producto), descripción, código de barra, código interno y
marca (o subgrupo, según cómo tengas configurado el campo de marca).

•  Por cada producto puedes editar y grabar (con el botón de check junto a

cada campo):

o  MIN: días mínimos de inventario para ese producto.

o  MAX: días máximos de inventario para ese producto.

o  MULT: múltiplo de compra (el sistema redondeará la cantidad sugerida

a múltiplos de este número; si tu cuenta usa "Múltiplo de bulto", este
campo se llena automáticamente con las unidades por bulto).

o  Casilla "Cendis": marca el producto para que se incluya en la

reposición centralizada (Cendis).

o  Casilla "Activar múltiplo": activa o desactiva que se aplique el

múltiplo de compra a ese producto.

•  Al final de la lista hay paginación.
