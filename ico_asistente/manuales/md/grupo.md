> **Audiencia: CLIENTE (Farmacia)** — Este documento aplica únicamente a usuarios cliente/farmacia. No uses esta información para responder consultas de proveedores.

NOTA PARA EL ASISTENTE (Ico): antes de explicar este módulo, verifica si el
usuario que pregunta pertenece a una cuenta tipo "Grupo". A diferencia de otras
funciones que se activan con un permiso, esto no es un simple interruptor: es
un tipo de cuenta distinto para cadenas con varias farmacias. Si el usuario NO
es tipo Grupo: no expliques el paso a paso, solo menciona que existe esta
funcionalidad (gestión centralizada de varias sucursales) y dile que debe
consultar con soporte si su negocio califica para configurar su cuenta como
Grupo. Si SÍ es tipo Grupo, explica el módulo con el detalle de abajo.

OPCION DE GRUPO

Este módulo solo aparece en el menú de clientes tipo "Grupo" (cadenas con
varias farmacias/sucursales conectadas bajo una misma cuenta). Es la pantalla
central para administrar las sucursales del grupo.

BARRA DE ACCIONES

•  "Inventario grupo": lleva al módulo de Inventario Grupo (ver su propio

manual), donde se consulta el inventario consolidado de todas las
sucursales.

•  "Pedidos grupo": solo aparece si trabajas bajo la modalidad de Pedido

Directo; lleva al consolidado de pedidos del grupo (ver "Pedido Directo").

TABLA DE SUCURSALES

Cada fila representa una sucursal del grupo, con:

•  OPCIÓN: botones para "Consultar cliente" (ver el detalle de esa sucursal)

y "Editar cliente" (abre la Configuración de esa sucursal).

•  ACTIVO: casilla para activar o desactivar la sucursal dentro del grupo.

•  PREDET: casilla para marcar esa sucursal como la predeterminada para tu

usuario.

•  VIS. INV: casilla que controla si esa sucursal puede visualizar el

inventario consolidado de todo el grupo.

•  CÓDIGO, NOMBRE (con la cadena, teléfono y contacto de la sucursal),

LOCALIDAD y ABREV. (descripción corta).

•  PREF.: nivel de preferencia de la sucursal, con flechas para subir o bajar

su prioridad dentro del grupo.

•  SINCRONIZADO: fecha y hora de la última sincronización del catálogo de

esa sucursal. Se pinta en amarillo si tiene 1 día de atraso, y en rojo si
tiene más de 1 día sin sincronizar.
