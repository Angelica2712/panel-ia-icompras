> **Audiencia: CLIENTE (Farmacia)** — Este documento aplica únicamente a usuarios cliente/farmacia. No uses esta información para responder consultas de proveedores.

OPCION DE DESCARGAR

Este módulo funciona como una central de descargas. Muestra tarjetas
clicables; cada una descarga o abre un archivo distinto. También registra cuántas
veces se ha descargado cada archivo.

•  Descargas generales: cualquier archivo que soporte haya publicado en

este módulo aparece como una tarjeta con su nombre, descripción y un
contador de "(N) descargas".

•  Descargas propias de tu cuenta (solo para clientes tipo "C" o "G", y si

tienes el permiso habilitado). NOTA PARA EL ASISTENTE (Ico): si el
usuario pregunta por la descarga de catálogo o RNK1 de proveedores y
no tiene ese permiso o no es cliente/grupo, no
expliques el paso a paso; solo menciona que existe esta funcionalidad y
dile que debe solicitar a soporte que se la activen.

o  "CATALOGO DE PRODUCTOS" (Proveedores): abre un formulario

donde eliges de qué proveedor quieres descargar el catálogo
(o "TPMAESTRA" para el catálogo consolidado de todos), y genera el
archivo.

o  "RNK1 DE PRODUCTOS" (Proveedores): mismo formulario, pero

descarga los productos donde ese proveedor tiene el mejor precio
(ranking 1).

•  Descarga de inventario (para clientes tipo "C" o "G"):

o  "INVENTARIO DE PRODUCTOS" (Clientes): abre un formulario para

elegir de qué cliente descargar el inventario. Si tu cuenta es
individual, solo puedes descargar el tuyo; si perteneces a un grupo,
puedes elegir "TCMAESTRA" (el inventario consolidado del grupo)
o el inventario de una sucursal específica del grupo (solo aparecen
las sucursales que sí tienen inventario sincronizado).

Mientras se genera cualquiera de estos archivos, aparece un overlay de carga
("Generando archivo, por favor espera...") y el botón "Confirmar" se deshabilita
hasta que termine la descarga.
